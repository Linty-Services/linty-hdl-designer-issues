# Linty HDL Designer Issues

This repository is where to file issues on [Linty HDL Designer](https://hdl-designer.linty-services.com/).

Issues can be:

- Bugs
- Improvements
- New features

## Filing an issue

[Open a new issue](https://github.com/Linty-Services/linty-hdl-designer-issues/issues/new/choose) and choose Bug, Improvement, or New feature.

For a bug, please include:

- The version of the Linty HDL Designer extension
- The editor (VS Code, Cursor, VSCodium, or another) and its version
- Your platform (Linux, Mac, Windows, or another)
- Details of the bug

For an improvement or a new feature, describe what you would like.
